# Governança: fininho-treino

- Esta constituição supera qualquer prática ad-hoc adotada durante o desenvolvimento. Onde
  código e constituição conflitarem, o código é o débito a corrigir, salvo emenda registrada
  abaixo.
- Mudanças exigem: aprovação do dono (Ednan) e PR própria que edita a constituição, numa branch
  `emenda-<versão>`, com o "porquê" no corpo do commit.
- Revisitar quando: entrar aluno real (LGPD), trocar de stack, ou o projeto deixar de ser de
  estudo.
- Versionamento: MAJOR para remoção ou reversão de princípio, MINOR para princípio novo, PATCH
  para redação ou clarificação.
