# fininho-treino

App de fichas de treino: o professor monta e atribui a ficha, o aluno registra a sessão feita.
Na conta do dono, a sessão se cruza com o treino medido pelo relógio
(fininho-watch).

Projeto de estudo de NestJS + Next.js, com especificação antes do código:

- `constitution/`: princípios, stack, workflow e governança
- `specs/BOARD.md`: roteiro de features
- `specs/_sistema/`: contratos compartilhados

Todos os dados do repositório são fictícios.
